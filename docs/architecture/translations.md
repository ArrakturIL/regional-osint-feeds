# Переводы и проверки качества (блок B)

Как сегодня устроен конвейер RU/HE. Ход работ и решения — в [STATUS](../STATUS.md), подробности по шагам — в PR #99–#209.

## Правила владельца (18.11)

- **Точность важнее скорости.** Перевод можно догрузить позже, а ошибку в смысле уже не отменишь.
- **Вывод — на языке страницы.** Переводим заголовок и вывод; полный текст может остаться на языке оригинала.
- **Какие оригиналы можно показывать без перевода:**
  - RU-страница: иврит и английский;
  - HE-страница: английский; **русский — нельзя**;
  - арабский без перевода — нигде.
- **Уровни важности** (`backend/editor/src/news/tier.mjs`):
  - `urgent` — угроза жизни: удары, сирены, приказы Командования тыла, закрытие неба или Ормуза;
  - `important` — решения правительств и армий, сигналы эскалации;
  - `normal` — всё остальное.
- **Сроки:** срочное ≤ 15 мин, важное ≤ 1 ч, обычное — по квотам.
- **Иврит — только с оригинала**, не с русского перевода.
- **Только бесплатные модели:** Cloudflare Workers AI и Gemini Free, без биллинга. Gemini получает только публичные тексты.

## Конвейер

```
новость / досье / аналитик / реплика
  → tier + нужен ли перевод для языка страницы
  → translation_jobs (одна очередь RU и HE): срочное → важное → обычное
  → router: цепочка моделей по задаче, общий учёт квот
  → ворота качества → отказ: следующая модель в цепочке
  → срочное и важное: сверка смысла второй моделью (не той, что переводила)
  → публикация  |  3 отказа или старше 72 ч → ручная очередь (видна в /ops; её разбирает GPT)
```

## Ворота качества

`translations/verify.mjs`, по порядку:

1. **Письменность:** в иврите нет арабских букв и кириллицы; слова не оборваны.
2. **Сущности и роли** — ручной глоссарий: КСИР, Кац, Ормуз и т. п.
3. **Смысловые правила:** отрицания, модальность, «кто что сделал».
4. **Имена из Wikidata** (`translations/glossary-wikidata.mjs`, 71 сущность, генерируется `wikidata-glossary.yml`). Проверяются только тексты длиной с заголовок (≤ 160 знаков); в ивритском оригинале имя ищется целым словом.
   Плюс:

- **Числа сохранены.**
  - RU: `validateCandidate` в `translations/news-mirror.mjs`; «6,7» = «6.7», «1 200» = «1,200».
  - HE: `translationPreservesNumbers` в `localization/scheduled.mjs`; числа 1–10 можно словами, «1970s» = «שנות ה־70».
- **Вторая модель** (`translations/meaning-check.mjs`) — только для срочного и важного. Последние вердикты с текстами видны в `/ops`.

## Известные ограничения

- Числа словами на иврите понимаются только от 1 до 10.
- «1,234» читается как тысячи, а не как десятичная дробь.
- Противоречие внутри самого оригинала (заголовок и описание говорят разное) вторая модель считает ошибкой перевода.
- «top 3» → «тройка» и `raf_misidentified` на верном «ВВС Великобритании» — ложные отказы, найдены в B6, не исправлены.
