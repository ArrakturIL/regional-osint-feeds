# Индекс напряжённости

Решение владельца 21.11: детерминированный индекс по сырым OSINT-данным, без ИИ. На сайте с первого дня, с пометкой «демо, идёт калибровка».

## Как считается

Каждые 5 минут Editor (`backend/editor/src/tension/tick.mjs`) досчитывает недостающие часы, не больше 12 за запуск. Первые запуски дозаполняют историю из `observations` (Monitor хранит 90 дней).

1. **Показатели** (`tension/indicators.mjs`) — числа по 5 регионам:

   | Семейство   | Показатель                                  | Источник                         | Окно    |
   | ----------- | ------------------------------------------- | -------------------------------- | ------- |
   | небо        | военные борта; заправщики и транспортники   | `mil_lol`                        | 6 ч     |
   | небо        | военные в выборке ADS-B (Иран, Залив)       | `adsb`, `adsb_alt`               | 6 ч     |
   | море        | «тёмные» суда к прошлой неделе (Залив)      | `gfw_sar`, `gfw_sar_baseline`    | неделя  |
   | земля       | тепловые точки (Иран, Залив, Ирак)          | `firms`                          | 1–2 сут |
   | земля       | новая активация картирования                | `copernicus_ems`                 | 72 ч    |
   | связь       | отключение интернета                        | `ioda`                           | 24 ч    |
   | новости     | срочные и важные новости по ключевым словам | `news_items` + `newsTier`        | 24 ч    |
   | новости     | события GDELT по странам                    | `gdelt_context`                  | 24 ч    |
   | официальное | новое предупреждение или новая редакция     | EASA, MARAD, UKMTO, FCDO, Госдеп | 72 ч    |

   Регионы: Иран; Израиль, Ливан, Сирия; Залив и Ормуз; Красное море и Йемен; Ирак.

2. **Норма.** Показатель сравнивается с его же значениями за 14 дней, без последних суток. Флаг — выше 95-го процентиля, выше абсолютного порога и в 1,5 раза выше медианы. Первые 3 дня истории показатель не флагуется. Событийные показатели (отключение, активация, предупреждение, «тёмные» суда ≥ 1,3 к прошлой неделе) флагуются сразу.
3. **Уровень** считает семейства, а не показатели: 0 семейств — 1, одно — 2, два — 3, три — 4, четыре или три с официальным — 5. Два вида ADS-B не дают «независимого подтверждения».
4. **Покрытие** — у скольких показателей региона были данные в окне.

## Где хранится и показывается

- D1 CORE `tension_hours(hour_ms, values_json, index_json)` — строка на час.
- `/api/overview` → `tension`: только коды и числа, одинаково для RU и HE. Старше 3 ч — `null`, блок скрыт.
- `/ops` → раздел «Индекс напряжённости»: значение каждого сигнала против нормы.
- Главная → блок `components/Tension` под «Главное сейчас».

## Сознательно не входит

- Гражданский трафик над Ираном: приёмники ADS-B там почти ничего не видят.
- AIS: выборка aisstream даёт в среднем 0,09 судна.
- Каталоги снимков Sentinel и OpenAerialMap отключены 21.11 (#242).

## Калибровка

История с 11.11; норма полная (30 дней) с 11.12. Пороги (`floor`, `rule`) — в `INDICATORS`; править по наблюдениям на `/ops`, с тестом в `tests/architecture/tension-index.test.mjs`.
