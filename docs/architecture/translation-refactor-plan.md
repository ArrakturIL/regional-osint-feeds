# Рефакторинг переводов и AI-проверок (блок B)

**Статус:** план утверждён владельцем голосом 18.11.2026 (решения ниже). Блок B снят с паузы. Реализация идёт поэтапно: на каждом этапе TDD, отдельный PR и проверка в production.

## Решения владельца (18.11.2026)

1. **Точность важнее скорости.** Перевод можно догрузить позже, а ошибку в смысле уже не отменишь.
2. **Вывод на языке страницы.** Переводим в первую очередь заголовок и вывод (summary). Полный текст может остаться на языке оригинала: аудитория в основном двуязычная или трёхъязычная.
3. **Какие оригиналы показывать без перевода:**
   - RU-страница: оригиналы на `he` и `en` можно показывать с пометкой «перевод готовится».
   - HE-страница: `en` показывать можно. **RU-оригинал на HE-странице без перевода запрещён.**
   - **Арабские оригиналы не показываем ни на одной странице без перевода.**
4. **Три уровня важности:**
   - **urgent** — угроза жизни и безопасности: удары, обстрелы, приказы Командования тыла, закрытие неба или Ормуза;
   - **important** — решения правительств и армий, сигналы эскалации;
   - **normal** — всё остальное.

   Уверенность считается отдельно: один источник или несколько независимых. У каждой новости есть короткая причина приоритета (reason code).
5. **SLA до сайта:** urgent ≤ 15 мин, important ≤ 1 ч, normal — по квотам.
6. **Аналитики** входят в этот рефакторинг, временных заплаток нет.
7. **Выжимать максимум из бесплатных моделей.** Cloudflare + Gemini Free, без биллинга.

## Факты аудита (18.11.2026, read-only)

- Cloudflare Workers AI: бесплатно 10 000 нейронов в день, общий пул на все модели. Фактический расход 11–17.11: **3,7–5,5 тыс. в день (40–55%)**.
- Каждый конвейер упирается в свой жёсткий лимит **каждый день**: RU news 20/20 batches, HE 112/112 attempts, ЦАХАЛ RU 12/12, комментарии 28/28, аналитики 14/14 (80 в очереди). Общего распределителя нет, поэтому ~5 тыс. нейронов в день сгорают.
- Модели: `llama-3.3-70b-instruct-fp8-fast` (RU, ЦАХАЛ, комментарии; ~55 нейронов за вызов), `glm-4.7-flash` (HE, аналитики, досье; ~12 нейронов за вызов).
- Покрытие RU за 48 ч: 172 из 251 (68%); хуже всего JNS (50%) и Al-Monitor (48%).
- HE: 17% попыток отклонены по `low_translation_confidence`. Защиты (`katz_name_corrupted`, `irgc_actor_missing`, `military_strikes_misread_as_labor_action`) реально срабатывают, то есть glm на иврите ошибается по существу.
- Gemini Free (квоты проекта по данным AI Studio, 16.11): Flash Lite 15 RPM / 500 RPD; 3.6/3.8 Flash 5 RPM / 20 RPD; Gemma 4 26B/31B 30 RPM / 16K TPM / 14.4K RPD. Ключ `GEMINI_API_KEY` лежит в Editor, в коде не используется. На free tier Google может использовать данные для улучшения продуктов, поэтому отправляем только публичные статьи.
- Helsinki Marian (en→ru, he→ru, en→he) работает в GitHub Actions каждые 2 ч (запуск через Monitor, SYS-01).

## Целевая архитектура

```
item → original_language + tier (urgent/important/normal, reason codes)
     → нужен ли перевод для страницы X (правила показа из решения 3)
     → очередь по tier → затем по свежести
     → router: задача → цепочка моделей с учётом квот (общий учёт: провайдер + день + RPM)
     → verify: глоссарий + сущности/числа/даты/отрицания/модальность/скрипт
          ok → publish · fail → retry на более сильной модели · снова fail → quarantine (не публикуется)
     → API: поле language_shown + translation_status на каждое поле
```

## Риски

- **Квоты Gemini** привязаны к проекту и могут меняться, поэтому router обязан пережить 429 и полное отсутствие Gemini.
- **Данные free tier Gemini** могут использоваться Google. Отправляем только публичные тексты, без секретов и персональных данных.
- **Shared D1:** схему меняем только аддитивно (новые таблицы и колонки), с идемпотентной миграцией в release preflight.

## Диагноз 19.11 (живые данные, Claude + независимый аудит GPT)

- **RU не имеет запасного пути.** Только llama-70B, свой потолок 48 пакетов × 5 / 6 000 нейронов (`translations/scheduled.mjs:20,42`), мимо router/budget B1–B2. 18.11 потолок выбран к 03:55Z → ~19 ч без RU. Резерва под urgent нет.
- **Окно 36 ч** (`scheduled.mjs:22`): не успевшее молча выпадает навсегда.
- **Нет учёта попыток RU по новости.** Отклонённая новость снова попадает в выборку. Сгорание квоты на повторах в работе не подтверждено (19.11: 8 пакетов → 37 переводов).
- **Нет проверки письменности.** 21 HE-перевод с арабскими буквами внутри слов, все от `gemini-3.5-flash-lite` (17% её HE), quality 95.
- **Смысл.** 4 подтверждённых искажения у Helsinki, glm и llama (роли, имена, пропавшие участники) — глоссарий их не видит.
- **Пять отдельных путей** (RU, HE, Helsinki, аналитики, досье) со своими квотами, проверками и повторами.
