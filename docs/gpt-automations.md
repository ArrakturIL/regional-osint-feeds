# Плановые задачи GPT: контракт с сайтом

Документ для GPT-задач в ChatGPT и для всех, кто их настраивает. Сам промпт хранится в ChatGPT, но каждая задача должна опираться на этот файл, а не на память чата. Если промпт и этот файл расходятся, верен файл.

## Роль

- GPT **обслуживает** сайт: досье, реплика редактора, ручные переводы, проверки. Основа — собственный конвейер сайта (Editor: очередь `translation_jobs`, ворота качества). Конвейер должен работать без GPT (решение владельца 19.11).
- Запуск — раз в час. Владельцу о новостях не писать, только об авариях (см. «Бюджет D1 и запреты»).
- Код, workflow, cron, секреты, квоты и схемы БД GPT не меняет. Это делает Claude с разрешения владельца.

## Задача 1 — «досье и здоровье сайта» (раз в час, :07)

- **Поиск событий — каждый прогон, до анализа источников** (добавлено 22.11: без этого шага 18 прогонов подряд не дали ни одного досье). Просмотреть NEWS `news_items` за последние 2 ч с `priority` ≥ 7 и `news_event_groups` с `priority` ≥ 4, обновлённые за 2 ч. Событие, подтверждённое официальным источником или ≥ 2 независимыми изданиями, которого ещё нет в `monitor_events` (сверка по теме, месту и дате), оформить досье в формате ниже. Не больше 3 новых досье за прогон.
- Неполные авиация, AIS и спутники не мешают досье по новостям: `outcome=partial` говорит только о сравнении источников, а не о поиске событий.

- **Прогон** — CORE `monitor_runs`: `run_id`, `started_at_ms`, `time_israel`, `outcome`, `payload`, `recorded_at_ms`. `outcome` строго одно из трёх:
  - `no_alert` — тревоги нет;
  - `alert` — есть существенное изменение;
  - `partial` — часть источников сравнить не удалось.
- **Досье** — CORE `monitor_events`: `event_id`, `category`, `first_seen` (дата события `ГГГГ-ММ-ДД`), `payload`, `updated_at_ms` (время записи; по нему сайт сортирует досье и считается их свежесть). Ключи `payload` — строго эти:
  - `title_ru` — до 240 знаков, конкретный;
  - `summary_ru` — до 1050;
  - `title` — по-английски, по желанию;
  - `sources: [{url, kind: official|party_claim|media, publisher}]` — первым идёт первоисточник;
  - `published_at`, `event_date`;
  - `confidence`, `assessment` — по желанию.
- **Иврит своих досье** — CORE `regional_i18n`: `kind='story'`, `model='gpt-ops-story'`. Перевод — с `title_ru`/`summary_ru`.
- **Пишет только в:** `monitor_runs`, `monitor_events`, `monitor_state`, `monitor_alerts`, CORE `regional_i18n` (`story`).

## Задача 2 — «реплика редактора и переводы» (раз в час, :37)

### Реплика — NEWS `editorial_notes` (решение владельца 21.11)

- **Тон:** цинично и саркастично, сухая ирония усталого редактора. Мишень — лицемерие, пиар, бюрократия, предсказуемость политиков и институтов. Чем тише новость, тем злее комментарий.
- **Не мишень:** жертвы и пострадавшие; национальные и религиозные группы как таковые; смерть и ранения. Никаких призывов к насилию и выдуманных цитат.
- **Частота:**
  - круглосуточно по времени Израиля, без суточного лимита; целевой интервал между репликами — 3–4 ч;
  - между репликами не меньше 3 ч, сюжеты не повторяются;
  - если с последней реплики прошло больше 4 ч, публиковать обязательно: «нет достаточно сильного повода» — не причина пропуска. Можно взять негромкую новость за последние 12 ч.
- **Проверка:** факт, над которым иронизируем, подтверждён первоисточником (официальное заявление) или двумя независимыми изданиями. Ирония — не факт; факты не искажать.
- **Поля:**
  - `id` — `rw-editorial-<тема>-<ГГГГММДД>`;
  - `topic_key`;
  - `headline` — до 90 знаков;
  - `text` — до 400 знаков, 1–3 предложения;
  - `source_url` — первоисточник;
  - `published_ms`, `created_ms`;
  - `verified_note` — что и по каким источникам проверено.
- **Иврит** GPT пишет сам и сразу: `regional_i18n` (NEWS), `kind='editorial'`, `model='gpt-editor'`. Сарказм — естественный для иврита, не дословный. В общую очередь сайта реплики не отдавать.

### Переводы — после реплики, до 10 за запуск

1. NEWS `translation_jobs`, `state='manual'` (сайт трижды не справился или задание старше 72 ч): сначала срочное, потом важное.
2. Просроченные `state='pending'`:
   - срочные старше 15 мин от `discovered_ms`;
   - важные старше 60 мин.
3. Как записывать:
   - **RU-новость:** `news_items.headline_ru`/`summary_ru`, только если они пустые.
   - **Иврит:** `regional_i18n`. `kind` — как в задании; для `story` — в CORE.
   - `model`: `gpt-ops-news` — перевод; `gpt-ops-repair` — исправление.
   - После записи заданию — `state='done'`.

Остальную очередь не трогать — её ведёт Editor.

## Правила перевода

- **Только с оригинала:** иврит не с русского, русский не с иврита-перевода.
- **Смысл важнее гладкости:** кто, что, кому — без подмен. Числа, даты, имена — как в оригинале. Не путать системы: «Праща Давида» ≠ «Железный купол».
- **Иврит:**
  - ни одной арабской буквы (U+0600–U+06FF) и ни одной кириллической;
  - сокращения — через ״ и ׳ (צה״ל), не через ASCII-кавычку.
- **Не уверен — не пиши.**

## Хэш оригинала `source_hash`

Без верного хэша сайт сочтёт перевод устаревшим и переведёт заново.

```python
import hashlib, json
v = lambda s, n: (s or '').strip()[:n]
# news:      [v(headline,260), v(summary,650), v(comment,300)]
# editorial: [v(headline,260), v(text,1900), '']
# story:     [v(title_ru,240), v(summary_ru,1050), '']
h = hashlib.sha256(json.dumps(LIST, ensure_ascii=False, separators=(',', ':')).encode()).hexdigest()
```

Это совпадает с `sourceText`/`fingerprint` в `backend/editor/src/localization/shared.mjs`.

## Бюджет D1 и запреты

- **Бюджет D1:** не больше 30 запросов за запуск. В каждом SELECT — `LIMIT` ≤ 200 и окно по времени. Исключение — таблицы состояния (одна строка на источник или ключ: `source_status`, `feed_status`, `regional_collector_cache` без `data_json`/`status_json`, `editor_state` по ключам): окно не ставится, иначе выпадет давно молчащий источник; обязательны `LIMIT` и только нужные колонки. Без `COUNT(*)` и `GROUP BY` по всей таблице. Лимит — 5 млн чтений в сутки; при превышении сайт падает до 02:00.
- **Нельзя:**
  - удалять строки;
  - писать в таблицы другой задачи;
  - менять сборщики, Workers, cron, секреты, AI-лимиты, `source_status`, `source_controls`;
  - включать ленты на паузе: JNS, Arutz Sheva, Guardian, Al-Monitor, Israel Hayom.
- **Отчёт:** каждый запуск перезаписывает один файл в Crosswalk `b7strikeball-agents`, до 3 КБ. Задача 1 — `ops/OPS_STATUS.md`, задача 2 — `ops/TRANSLATION_STATUS.md`.
- **Владельцу писать только при аварии:**
  - сайт или API отвечает не 200 два запуска подряд;
  - пуст `/api/news`;
  - все досье старше 24 ч — по `updated_at_ms`, не по `first_seen`;
  - запись в D1 не проходит два запуска подряд.
