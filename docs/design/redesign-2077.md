# Редизайн: направление «2077» (решение владельца 18.11)

Холст с концептами: https://claude.ai/artifact/Sg5XgcWwEWGjwJjaUh3YhY — выбран **E · 2077** (основа — C «Тихая карта»).

## Что берём
- Тёмная тема, зелёная гамма: фон `#050b09`, акцент мятный `#9ff5c6`, срочно `#f3a59b`, важно `#efd09a`, текст `#e9fbf1`, вторичный `#c4e0d0`.
- Шрифты: Unbounded (заголовки), Manrope (текст), JetBrains Mono (служебные метки капсом с разрядкой). Для HE подобрать пару с ивритом.
- HUD-геометрия: срезанные углы панелей, тонкие линии, метки сигналов `SIG-NN`, сегментная полоса источников (1 сегмент = 1 источник).
- Фон шапки: точечная сетка, дышащее контурное поле, пунктир-поток, медленный луч сканера; подпись «схема, не карта».

## Чего не делаем
Глитч, голографические отливы, неон, glassmorphism.

## Анимации полного дизайна
Элегантно и сдержанно, в стиле E: переходы между разделами, раскрытие карточек, появление списков, hover-указатели. Без перегруза. `prefers-reduced-motion` выключает движение.
