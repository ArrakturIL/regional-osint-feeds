## Технический долг

- D1 CORE: триггеры `monitor_runs_link_events_*` (`UPDATE monitor_runs AS m …`) не проходят проверку SQLite при `ALTER TABLE … RENAME` любой таблицы. Сами триггеры работают. Миграции делать через пересоздание таблицы, без RENAME (как `storage/cloudflare/006`).
- Frontend собирается склейкой файлов по `build-order.json`, `import` вырезаются регулярным выражением. Строки i18n зашиты в компоненты. `frontend/tests` и `frontend/scripts` не отформатированы Prettier.
- Legacy `worker/`, `baselines/`, `site/` (~900 КБ) не входят в release. Удалять только с доказательством, что они не используются.
