- ○ **Индекс напряжённости (идея владельца 18.11, по образцу Pizza Index):** общая напряжённость в регионе 1–5 с причиной. Каждый сигнал сравнивается со своей нормой за 30 дней (военные рейсы, закрытия неба, морские предупреждения, срочные новости, GDELT, Polymarket). Расчёт детерминированный, без AI. Учитываются только живые источники, рядом показывается покрытие «N из M». Заменит пустой блок «Главное из последнего анализа» на главной.
