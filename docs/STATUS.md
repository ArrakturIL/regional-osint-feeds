## 4. Ограничения и технический долг

- **Cloudflare Observability с 01.12.2026** тарифицируется по объёму. На Free — 0,5 ГБ в сутки и хранение 7 дней. В наших конфигурациях она не включена. Подробное логирование не добавлять; платные планы — только с разрешения владельца.
- **D1 CORE:** без `ALTER TABLE … RENAME` (мешают триггеры `monitor_runs_link_events_*`). Таблицу пересоздавать копированием, как `storage/cloudflare/006`.
- **Frontend** собирается склейкой по `build-order.json` (имена верхнего уровня должны быть уникальны). Строки i18n зашиты в компоненты; порядок слоёв CSS — в [docs/design/redesign-2077.md](design/redesign-2077.md).

## 5. Границы для агентов

Без явного разрешения владельца не делать: production merge/deploy, запись в production D1/Neon (preview делит bindings), cron, секреты, платные квоты и AI-лимиты, новые Workers. Разрешение, выданное в чате одному агенту, другим не передаётся.
