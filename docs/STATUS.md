## Известный технический долг

- Тесты: много проверок по подстроке SQL и побайтовому совпадению с baseline от 14.11 (`baselines/`). Они цементируют legacy и не ловят ошибки проводки. E-01 прошёл через все такие тесты. Новые тесты писать поведенческими, через реальный entrypoint.
- Код в «минифицированном» стиле (строки до 3000 символов) мешает ревью.
- Frontend собирается склейкой файлов по `build-order.json` с вырезанием `import` регэкспом. Строки i18n зашиты в компоненты.
- Legacy: `worker/`, `baselines/`, `site/` (~900 КБ) не входят в активный release. Удалять только с доказательством неиспользования (см. ARCH-06).
